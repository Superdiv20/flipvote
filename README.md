# Flipvote
A simple, fast planning poker app for estimating stories together in real time. Create a room, share the link, and everyone votes with hidden cards until the facilitator reveals them.

No accounts needed. Pick a name and join.
Realtime. WebSocket-powered, with seamless reconnects.
Fair by design. Votes stay on the server until the reveal.
Flexible decks. Fibonacci, T-shirt sizes, or your own.
Self-hostable. One Docker container, SQLite included, no external dependencies.

Built with Bun on the backend and Angular + Spartan UI on the frontend.
